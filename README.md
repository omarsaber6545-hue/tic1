# 🤖 نظام ديسكورد العربي الاحترافي المتكامل (Bot & Web Dashboard)

نظام متكامل وحقيقي بنسبة 100% باللغة العربية لإدارة سيرفرات ومجتمعات Discord، مصمم بأعلى معايير الأمان والسرعة والاحترافية. يجمع بين بوت متطور مبني بأحدث إصدار من **Discord.js v14** مع **TypeScript**، وقاعدة بيانات سحابية متينة بـ **Prisma ORM & PostgreSQL**، ولوحة تحكم ويب عصرية فائقة السرعة مبنية بـ **Next.js 14** و **Tailwind CSS** بتصميم Dark Glassmorphism ودعم كامل للغة العربية والـ RTL.

---

## 🌟 المميزات والأنظمة الرئيسية

### 1. ⭐ نظام النقاط والمستويات (Points & Levels)
- **احتساب النقاط والـ XP**: يحصل العضو على نقاط وXP تلقائياً عند التفاعل والحديث مع نظام Cooldown لمنع السبام.
- **معادلة مستويات ديناميكية**: `XP = 5 * (Level^2) + 50 * Level + 100`.
- **بطاقة الرتبة (Rank Card)**: بطاقة SVG بدقة فائقة تعرض صورة العضو، مستواه، نقاطه، رتبته في السيرفر، وشريط تقدم أنيق.
- **إشعارات الترقية التلقائية**: رسائل مباركة مخصصة في نفس الروم أو في روم مخصص للترقيات.
- **المكافآت اليومية والأسبوعية**: `/يومي` و `/أسبوعي` مع مؤقتات دقيقة لمنع التكرار.
- **لوحة المتصدرين**: `/المتصدرين` لترتيب الأعضاء بحسب النقاط أو بحسب المستوى.
- **أوامر الإدارة**: `/إضافة-نقاط`، `/خصم-نقاط`، `/تعيين-نقاط`، `/إضافة-xp`، `/تعيين-مستوى`.

### 2. 🎫 نظام التذاكر المتكامل (Tickets System)
- **لوحة التذاكر التفاعلية**: رسالة Embed فخمة مع زر "فتح تذكرة" وقائمة منسدلة (Select Menu) لاختيار القسم:
  - 🛠️ الدعم الفني
  - 🛒 المشتريات
  - 💰 الدفع والفوترة
  - 🚨 الإبلاغ والشكاوى
  - 🤝 الشراكات والإعلانات
  - ❓ استفسار آخر
- **رومات خاصة ومشفرة الصلاحيات**: عزل القناة ومنع الوصول لغير صاحب التذكرة وفريق الدعم والإدارة.
- **أزرار التذكرة التفاعلية**:
  - 📌 **استلام التذكرة**: تثبيت الموظف المستلم وقفل الزر لمنع الازدواجية وتسجيل ذلك في السجل.
  - 🔒 **إغلاق التذكرة**: نافذة تأكيد، إنشاء Transcript كامل، إرسال نسخة لصاحب التذكرة في الخاص، وحذف الروم بعد 5 ثوانٍ.
  - ✏️ **تغيير الاسم**: تعديل اسم روم التذكرة عبر Modal فوري.
  - ➕ **إضافة عضو**: إضافة عضو للتذكرة بالـ ID.
  - ➖ **إزالة عضو**: سحب صلاحيات أي عضو من التذكرة.
  - 📄 **تحميل Transcript**: توليد ملف HTML متكامل بتنسيق ديسكورد Dark مع صور الأعضاء وتواريخ الرسائل.

### 3. 🛡️ نظام الإشراف والإدارة (Moderation & Security)
- فحص صارم للصلاحيات وتسلسل الرتب (Role Hierarchy) لمنع استغلال الصلاحيات أو معاقبة من هو أعلى رتبة من البوت أو المشرف.
- أوامر إدارية كاملة باللغة العربية:
  - `/حظر`، `/فك-الحظر`
  - `/طرد`
  - `/تايم-اوت`، `/إزالة-التايم-اوت`
  - `/مسح` (مسح حتى 100 رسالة مع فلتر اختياري لعضو محدد)
  - `/قفل`، `/فتح`
  - `/بطء` (Slowmode)
  - `/تغيير-الاسم`
  - `/إضافة-رتبة`، `/إزالة-رتبة`

### 4. ⚠️ نظام التحذيرات والتصعيد التلقائي (Warnings & Auto-Escalation)
- حفظ التحذيرات في قاعدة البيانات مع رقم المعرف، اسم المشرف، والسبب.
- أوامر: `/تحذير`، `/تحذيرات`، `/إزالة-تحذير`، `/مسح-تحذيرات`.
- **التصعيد التلقائي المخصص**:
  - 3 تحذيرات ⬅️ تايم أوت تلقائي (ساعة)
  - 5 تحذيرات ⬅️ طرد فوري (Kick)
  - 7 تحذيرات ⬅️ حظر نهائي (Ban)

### 5. 🚨 نظام الحماية التلقائية (AutoMod)
- **Anti Spam**: كشف إرسال الرسائل بسرعة فائقة وعزل العضو.
- **Anti Flood**: كشف الرسائل الطويلة جداً وتكرار الحروف.
- **Anti Invite**: منع نشر روابط سيرفرات الديسكورد الأخرى.
- **Anti Links**: حظر الروابط الخارجية غير المصرح بها.
- **Anti Duplicate**: منع تكرار نفس الرسالة.
- **Mention Spam**: منع المنشن المزعج للرتب والأعضاء.
- **فلتر الكلمات الممنوعة**: فحص الكلمات وتطبيق العقوبة المحددة (حذف، تحذير، تايم أوت، طرد، حظر).

### 6. 👋 نظام الترحيب (Welcome & Auto-Role)
- رسالة ترحيب مخصصة مع منشن وصورة العضو وإحصائية الأعضاء.
- دعم المتغيرات: `{user}`, `{server}`, `{count}`.
- منح رتبة تلقائية فورية للأعضاء الجدد (Auto-Role).
- إمكانية تفعيل رسالة ترحيبية خاصة بالـ DM.

### 7. 💡 نظام الاقتراحات (Suggestions)
- أمر `/اقتراح` لنشر الاقتراح في الروم المخصص.
- تصويت تفاعلي بأزرار 👍 و 👎 مع عدادات حية ومنع تكرار التصويت.
- زر إداري للمشرفين لقبول أو رفض الاقتراح مع إمكانية كتابة السبب وتحديث الرسالة.

### 8. 🎉 نظام المسابقات التلقائي (Giveaways)
- أوامر: `/مسابقة إنشاء`، `/مسابقة إنهاء`، `/مسابقة إعادة-اختيار`.
- اشتراط رتبة معينة أو عدد نقاط للدخول.
- جدولة خلفية تلقائية تختار الفائز عشوائياً وتعلن النتيجة وتحدث السجلات.

### 9. 🪙 نظام الاقتصاد والمتجر (Economy & Shop)
- رصيد محفظة ورصيد بنك مع عملة مخصصة ورمز مخصص.
- أوامر: `/رصيدي`، `/تحويل`، `/المتجر`، `/شراء`، `/حقيبتي`.
- متجر السيرفر: رتب وامتيازات قابلة للشراء بالعملة مع منح الرتبة للمشتري تلقائياً وحفظها في الحقيبة.

### 10. 📜 نظام السجلات المتقدم (Audit Logs)
- رومات مخصصة أو روم عام لكل من:
  - سجلات دخول وخروج الأعضاء
  - سجلات حذف وتعديل الرسائل
  - سجلات الإشراف (حظر، طرد، تحذير، تايم أوت)
  - سجلات التذاكر (فتح، استلام، وإغلاق مع مرفق الـ Transcript)
  - سجلات الرتب والقنوات وتغييرات السيرفر

### 11. 💻 لوحة التحكم السحابية (Next.js Web Dashboard)
- واجهة Dark Mode فائقة الجمال مع مؤثرات Glassmorphism وانتقالات سلسة.
- اتجاه RTL كامل مخصص للمستخدم العربي.
- تزامن فوري 100% مع قاعدة البيانات والبوت دون الحاجة لإعادة التشغيل.
- عارض مدمج لسجلات التذاكر (HTML Transcript Viewer) بضغطة زر.

## 🛠️ التقنيات المستخدمة

- **البيئة**: Node.js v24+
- **لغة البرمجة**: TypeScript (Strict Mode)
- **مكتبة الديسكورد**: Discord.js v14
- **قاعدة البيانات**: PostgreSQL مع Prisma ORM
- **لوحة التحكم**: Next.js 14 (App Router) + Tailwind CSS + Lucide Icons

## 🚀 طريقة التثبيت والتشغيل

### 1. إعداد المتغيرات البيئية (`.env`)
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
وقم بملء البيانات الخاصة بك:
- `DISCORD_TOKEN`: توكن البوت من بوابة مطوري ديسكورد (Discord Developer Portal).
- `CLIENT_ID`: معرف تطبيق البوت (Application ID).
- `DATABASE_URL`: رابط الاتصال بقاعدة بيانات PostgreSQL:
  ```env
  DATABASE_URL="postgresql://postgres:password@localhost:5432/arabic_discord_bot?schema=public"
  ```

### 2. تثبيت الحزم وتجهيز قاعدة البيانات
```bash
# تثبيت حزم البوت الرئيسي
npm install

# توليد عميل Prisma وتطبيق الجداول على قاعدة البيانات
npx prisma db push
npx prisma generate

# تثبيت حزم لوحة التحكم
npm --prefix dashboard install
```

### 3. تشغيل البوت (Discord Bot)
```bash
# تشغيل البوت في وضع التطوير (مع التحديث التلقائي)
npm run dev

# أو البناء والتشغيل للإنتاج:
npm run build
npm start
```

### 4. تشغيل لوحة التحكم (Web Dashboard)
في نافذة طرفية منفصلة:
```bash
# تشغيل لوحة التحكم في وضع التطوير:
npm run dashboard:dev

# أو البناء للإنتاج:
npm run dashboard:build
npm run dashboard:start
```
افتح المتصفح على الرابط: `http://localhost:3000` للدخول إلى لوحة التحكم فورياً.

## 🔒 الصلاحيات والأمان
- تأكد من تفعيل خيارات **Privileged Gateway Intents** في Discord Developer Portal:
  - `Presence Intent`
  - `Server Members Intent`
  - `Message Content Intent`
- يجب أن تكون رتبة البوت في السيرفر أعلى من الرتب التي يديرها لضمان عمل أوامر الإشراف وحماية الرتب بشكل صحيح.
